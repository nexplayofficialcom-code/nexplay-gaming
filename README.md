# NEXPLAY Gaming Platform

A responsive static gaming website with 17 game listings, a playable Neon Target Rush browser game, and a device-local leaderboard.

## Free deployment
Upload `index.html` to the root of a GitHub repository. Connect the repository to Cloudflare Pages using the `None` framework preset, no build command, and `/` output directory.

## Current limits
This is a working starter site, not a production tournament backend. There is no real login, cash reward, entry payment, server leaderboard, or tournament registration. Cash prize displays are proposals only and require legal review, funding and appropriate third-party game permissions.

## Visual update
Game Arena no longer shows a game count. Game tiles use clearly labeled wordmarks instead of emoji placeholders. Official third-party game logos are not included without verified brand assets/permissions.


## Logo sources
Game Arena has no game-count heading. BGMI uses a Wikimedia Commons copy of the original BGMI wordmark. Free Fire and PUBG Mobile have remote logo URLs that may fail; the UI falls back to text. Official publisher brand assets: https://www.freefiremobile.com/en/brand/ and https://www.pubgmobile.com/en/event/brandassets/ . Verify brand permission before commercial publication. Generic categories do not have one universal official logo.

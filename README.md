# NEXPLAY Gaming Platform

A responsive static gaming website with 17 game listings, a playable Neon Target Rush browser game, and a device-local leaderboard.

## Free deployment
Upload `index.html` to the root of a GitHub repository. Connect the repository to Cloudflare Pages using the `None` framework preset, no build command, and `/` output directory.

## Current limits
This is a working starter site, not a production tournament backend. There is no real login, cash reward, entry payment, server leaderboard, or tournament registration. Cash prize displays are proposals only and require legal review, funding and appropriate third-party game permissions.
